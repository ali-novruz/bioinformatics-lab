# Bioinformatik düşüncə

Bioinformatika bioloji sualı hesablana bilən ölçü, model və yoxlama planına çevirir. Computational biology modeldən yeni izah və proqnoz çıxarmağa fokuslana bilər; sərhəd sərt deyil.

### Başlanğıc
Bioloji replikat müstəqil bioloji vahiddir, technical replicate isə eyni vahidin təkrar ölçməsidir. Sequencing read sayı sample size deyil. Referens genom, annotasiya və sample metadata üç ayrı obyekt kimi saxlanmalıdır.

### Praktik protokol
Sual → ölçülə bilən hipotez → nümunə seçimi → xam data → QC → metod → effect size/uncertainty → interpretasiya. Əvvəl mənfi kontrol və uğur meyarını yazın. Faylın checksum-u məzmunun bütövlüyünü göstərir, biological quality-ni yox.

### Advanced
Reproducibility eyni data/kodla nəticəni əldə etməkdir; yeni kohortda generalization ayrıca sınaqdır. Batch correction nəticəyə baxıb tənzimlənərsə məlumat sızması yarada bilər. Texniki keyfiyyət və bioloji variasiyanı ayırmaq üçün dizayn kovariatı, randomization və replication lazımdır.

### Tapşırıq
Pasilla üçün experimental unit, treatment, sequencing type və outcome-u yazın. WDBC-də target ilə predictor-un eyni klinik prosesdən necə yarandığını izah edin.
