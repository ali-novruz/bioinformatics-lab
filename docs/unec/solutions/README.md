# Cavablar və izahlar

Bu səhifəni yalnız [tapşırıqları](../exercises/README.md) tamamladıqdan sonra açın. Cavabınız fərqli, amma əsaslandırılmışdırsa onu avtomatik səhv saymayın; fərziyyələri müqayisə edin.

## Məlumat və SQL

1. `sample_id` identifikator, `condition` kateqoriya, `count` tam sayımdır.
2. `sample_id` kimi sabit açar üzrə join edilməlidir; sətir sırası açar deyil.
3. SHA-256 bayt uyğunluğunu yoxlayır, mənbə və metodun elmi doğruluğunu yox.
4. `124 × 6 = 744` qeyd.
5. Birləşmiş əsas açarı və ölçmənin unikallığını pozur.
6. Raw count qeyri-mənfi tam ədəddir; TPM üçün ayrıca sxem lazımdır.

## ML və genetika

7. Validation məlumatı seçimə sızır; seçim hər training fold daxilində edilməlidir.
8. `(1 + 5/6 + 1 + 1) / 4 = 23/24 = 0.95833`.
9. Test müstəqil son qiymətləndirmə rolunu itirir; yeni untouched data lazımdır.
10. `0/1` unphased, `0|1` phased genotipdir.
11. REF referens alleldir, sağlamlıq etiketi deyil.
12. Poligenlik çox genin bir xüsusiyyətə, pleiotropiya bir genin bir neçə xüsusiyyətə təsiridir.

## Axtarış və statistika

13. BLASTX.
14. Xeyr; coverage, təsadüfi uyğunluq, konservasiya və funksional sübut lazımdır.
15. Xeyr; score və alignment uzunluğu müxtəlif ölçülərdir.
16. Gözlənilən qiymət `1000 × 0.05 = 50`-dir; hər realizasiyada dəqiq 50 olmur.
17. Xeyr; p-value H0/model şərti altında daha ekstremal statistikanın ehtimalıdır.
18. Xeyr; BH uyğun şərtlərdə yanlış discovery payının gözlənilən qiymətini idarə edir.

## Təkrar icra və iddia

19. `*` elementlər üzrə, `@` matris vurmasıdır.
20. Bəli; alqoritm və numeric kitabxana versiyası dəyişə bilər.
21. Mütləq deyil; run kimliyi ilə elmi output ayrıca müqayisə edilməlidir.
22. Xeyr; skrininq populyasiyası, mərhələ, nəzarət və xarici validasiya yoxdur.
23. Xeyr; əvvəl probe-gen xəritəsi və müstəqil biologiya sübutu lazımdır.
24. Xeyr; ilkin data və metodla ayrıca icra olunmadan bu, tədris xülasəsidir.
