# UNEC materiallarından praktik bioinformatikaya

Bu bölmə istifadəçinin təqdim etdiyi 68 fayldan seçilmiş mövzuları repo ilə bağlayır. Materialların müəllifliyi saxlanılır; konspekt və tapşırıqlar bu laboratoriya üçün yenidən hazırlanıb. Bu, UNEC tərəfindən təsdiqlənmiş rəsmi dərslik deyil.

## İstifadə ardıcıllığı

1. [Mənbə kataloqu](../../resources/unec/README.md): hansı fayl istifadə edilib, hansı hissə oxunub.
2. [Səkkiz praktik dərs](handbook.md): anlayış, nümunə, mənbə və yoxlama meyarı.
3. [15 həftəlik proqram](course-plan.md): həftəlik nəticə və keçid meyarı.
4. [24 tapşırıq və mərhələ yoxlamaları](exercises/README.md): əvvəl özünüz həll edin.
5. [Ayrı cavab və izah açarı](solutions/README.md): yalnız həll cəhdindən sonra açın.
5. [Mənbələrdə dəqiqləşdirmələr](errata.md): köhnə və ya yanlış iddiaların düzəlişi.
7. [PDF praktikum](../../resources/unec/bioinformatika-praktikum.pdf): oflayn oxumaq üçün eyni əsas dərslər və tapşırıqlar.
