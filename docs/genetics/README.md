# Genetika və koordinatlar

Allel bir lokusun alternativ formasıdır; heterozygous diploid nümunə iki fərqli allel daşıyır. Genotype→phenotype əlaqəsi penetrance, mühit, çoxgenli təsirlər və ölçmə xətası ilə mürəkkəbləşir.

### Əsas hesablama
Diploid, autosomal və tam çağırılmış nümunələrdə ALT allele frequency = ALT allel sayı / çağırılmış allel sayı. Missing GT məxrəcdən çıxır. Hardy–Weinberg testinin fərziyyələri populyasiya qarışması və selection olduqda pozula bilər.

### Variant şərhi
SNV, insertion/deletion, copy-number və rearrangement fərqli ölçmə metodları tələb edir. “Nonsynonymous” avtomatik “pathogenic” deyil. Transcript, strand, reference build və ClinVar assertion tarixi birlikdə yazılmalıdır.

### Eksperiment
Eyni SNP üçün yalnız PASS çağırışlar və bütün çağırışlarla allele frequency-ni müqayisə edin. Kiçik nümunə, ancestry və missingness nəticəni necə dəyişir? Əlavə sual: call-rate iki phenotype qrupunda fərqlidirmi?
