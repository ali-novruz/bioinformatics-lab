# Uzun oxunuş formatları

ONT POD5 raw current-signal, PacBio BAM isə subread/HiFi read və platform tag-lərini daşıya bilər. Basecalled FASTQ keyfiyyəti Phred-dir, lakin error profili short-read ilə eyni deyil. BAM görmək paired-end Illumina fərziyyəsinə əsas vermir.

QC: yield, median və N50 read length, quality paylanması, adapter/chimera, platform, basecaller və model versiyası. Assembly üçün coverage və read-length; variant calling üçün platform-specific calibration ayrıca qiymətləndirilir. [ONT POD5](https://pod5-file-format.readthedocs.io/) · [PacBio BAM](https://pacbiofileformats.readthedocs.io/).
