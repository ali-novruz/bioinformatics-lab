### İstifadə edilmiş prompt

> Use case: stylized-concept. Asset type: wide cover banner for the GitHub README of an existing bioinformatics teaching and research repository. Create a polished editorial science cover, panoramic 3:1 composition, ideally 1800x600. Deep midnight navy background, restrained teal and mint accents with warm off-white typography, consistent with teal scientific figures. Main subject: a beautifully rendered translucent DNA double helix flowing diagonally across the right half, with restrained molecular points and thin sequence-like lines, elegant depth, scientific illustration rather than a literal data result. Left half has generous negative space and very large immaculate sans-serif typography. Text verbatim on two lines: 'BIOINFORMATICS' and 'RESEARCH LAB'. Small eyebrow above: 'LEARN · BUILD · TEST'. The main title must be the strongest visual element, perfectly legible when the entire banner is displayed at 900 pixels width. Fine subtle grid in background, no busy circuitry, no fake numeric results or axes, no badges, no device mockup, no watermark, no institutional logos. Flat edge-to-edge banner asset with calm spacing, premium restrained design, no external frame.
