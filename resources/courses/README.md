# Kurslar

- [EMBL-EBI Training](https://www.ebi.ac.uk/training/): UniProt, ENA, expression və data resursları. Tapşırıq: bir accession-u iki xidmət arasında izləmək.
- [Galaxy Training Network](https://training.galaxyproject.org/): RNA-seq, variant calling, metagenomics. Tapşırıq: Galaxy workflow addımlarını CLI ilə müqayisə etmək.
- [Software Carpentry](https://software-carpentry.org/lessons/): shell, Git, Python/R. Tapşırıq: bir təmiz mühitdə repository-ni yenidən işlətmək.
- [Rosalind](https://rosalind.info/): DNA və sequence algorithm məsələləri. Tapşırıq: edge case-lərlə test edilmiş 10 həll.
- [Bioconductor Workflows](https://bioconductor.org/help/workflows/): real analiz dizaynı. Tapşırıq: metadata və design matrix audit-i.

Kurs bitirmək keçid meyarı deyil; roadmap-dəki işlək nəticəni və izahı təqdim etmək əsasdır.
