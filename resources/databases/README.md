# Databazalar

- [NCBI](ncbi.md): Molekulyar biologiya və elmi informasiya xidmətləri üçün portal.
- [GenBank](genbank.md): Nukleotid sequence arxivi, INSDC tərəfdaşı.
- [PubMed](pubmed.md): Biotibbi ədəbiyyat indekslənməsi.
- [GEO](geo.md): Functional genomics eksperiment arxivi.
- [SRA](sra.md): Xam sequencing read arxivi.
- [ENA](ena.md): Avropa nukleotid arxivi və INSDC tərəfdaşı.
- [UniProt](uniprot.md): Protein sequence və funksiya annotasiyası.
- [PDB](pdb.md): Eksperimental makromolekul struktur arxivi.
- [Ensembl](ensembl.md): Genome annotation və comparative genomics.
- [UCSC Genome Browser](ucsc-genome-browser.md): Genom track-lərinin koordinatla göstərilməsi.
- [dbSNP](dbsnp.md): Kiçik genetik variantların qeydiyyatı.
- [ClinVar](clinvar.md): Variant və sağlamlıq əlaqəsi haqqında təqdim edilmiş şərhlər.
- [OMIM](omim.md): Mendel irsiyyəti və insan gene–phenotype bilik bazası.
- [STRING](string.md): Protein functional association şəbəkəsi.
- [KEGG](kegg.md): Pathway, reaction və molekulyar sistem bilik bazası.
- [Reactome](reactome.md): Kurasiya edilmiş bioloji reaksiyalar və pathways.
- [GTEx](gtex.md): İnsan toxumalarında expression və genetic regulation.
- [TCGA](tcga.md): Xərçənglərin molekulyar profillənməsi proqramı; data əsasən GDC vasitəsilə.
