# PDB

## Məqsəd
Eksperimental makromolekul struktur arxivi.
## Saxlanan məlumat
Koordinatlar, entity/chain, ligand, experimental method və validation metadata.
## Data əldə etmə və API
RCSB Data/Search API; mmCIF/PDB download; PDBe API alternativi.
## İstifadə halı
1CRN Cα contact map.
## Layihə fikri
Eyni protein ailəsinin ligandlı və ligandsız strukturları.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [PDB](https://www.rcsb.org/docs/programmatic-access/web-apis-overview). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
