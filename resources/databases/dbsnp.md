# dbSNP

## Məqsəd
Kiçik genetik variantların qeydiyyatı.
## Saxlanan məlumat
rs ID, allele və placement/frequency metadata.
## Data əldə etmə və API
NCBI Variation Services və FTP; build və rs merge tarixçəsi vacibdir.
## İstifadə halı
rs ID-ni düzgün referens mövqeyinə bağlamaq.
## Layihə fikri
rs ID dəyişmələrinin pipeline nəticəsinə təsiri.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [dbSNP](https://www.ncbi.nlm.nih.gov/snp/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
