# TCGA

## Məqsəd
Xərçənglərin molekulyar profillənməsi proqramı; data əsasən GDC vasitəsilə.
## Saxlanan məlumat
Expression, somatic variation, copy-number, methylation və clinical metadata.
## Data əldə etmə və API
GDC portal, API və transfer tool. Open/controlled giriş ayrılır.
## İstifadə halı
Cancer subtype və survival sualları.
## Layihə fikri
TCGA daxilində donor-aware multi-omics baseline.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [TCGA](https://gdc.cancer.gov/access-data/developers). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
