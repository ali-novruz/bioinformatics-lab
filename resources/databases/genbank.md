# GenBank

## Məqsəd
Nukleotid sequence arxivi, INSDC tərəfdaşı.
## Saxlanan məlumat
Sequence, accession.version, feature və submitter metadata.
## Data əldə etmə və API
NCBI Nucleotide/EFetch, FTP və Datasets.
## İstifadə halı
Mikrob genomları və CDS-lərin müqayisəsi.
## Layihə fikri
Eyni növün 10 genomunda gen mövcudluğu.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [GenBank](https://www.ncbi.nlm.nih.gov/genbank/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
