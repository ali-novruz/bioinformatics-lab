# KEGG

## Məqsəd
Pathway, reaction və molekulyar sistem bilik bazası.
## Saxlanan məlumat
Genes, orthology, compounds, reactions, pathways.
## Data əldə etmə və API
REST API və web; kommersiya/bulk istifadə şərtlərini ayrıca yoxlayın.
## İstifadə halı
Metabolic pathway mapping.
## Layihə fikri
Mikrob community-də functional pathway coverage.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [KEGG](https://www.kegg.jp/kegg/rest/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
