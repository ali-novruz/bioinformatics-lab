# PubMed

## Məqsəd
Biotibbi ədəbiyyat indekslənməsi.
## Saxlanan məlumat
Bibliographic metadata, abstract və full-text linkləri; bütün məqalələrin tam mətni deyil.
## Data əldə etmə və API
Web və E-utilities API; PMID və DOI-ni saxlayın.
## İstifadə halı
Metodun ilkin məqaləsini tapmaq.
## Layihə fikri
Variant caller müqayisələrinin inclusion/exclusion cədvəli.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [PubMed](https://pubmed.ncbi.nlm.nih.gov/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
