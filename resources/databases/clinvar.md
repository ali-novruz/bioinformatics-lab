# ClinVar

## Məqsəd
Variant və sağlamlıq əlaqəsi haqqında təqdim edilmiş şərhlər.
## Saxlanan məlumat
Clinical significance assertions, review status, phenotype, submitter və dates.
## Data əldə etmə və API
NCBI web, FTP XML/VCF və Entrez; VCF bütün ClinVar məlumatını təmsil etmir.
## İstifadə halı
Conflicting interpretation-ları araşdırmaq.
## Layihə fikri
Review status üzrə prioritization həssaslığı.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [ClinVar](https://www.ncbi.nlm.nih.gov/clinvar/docs/maintenance_use/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
