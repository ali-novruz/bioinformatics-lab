# UCSC Genome Browser

## Məqsəd
Genom track-lərinin koordinatla göstərilməsi.
## Saxlanan məlumat
Referens, annotation, conservation və community tracks.
## Data əldə etmə və API
Table Browser, track downloads və REST JSON API.
## İstifadə halı
BED regionlarının gene/track overlap-u.
## Layihə fikri
Disease-associated loci üçün annotation atlası.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [UCSC Genome Browser](https://genome.ucsc.edu/goldenPath/help/api.html). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
