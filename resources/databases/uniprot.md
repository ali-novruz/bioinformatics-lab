# UniProt

## Məqsəd
Protein sequence və funksiya annotasiyası.
## Saxlanan məlumat
Swiss-Prot reviewed, TrEMBL unreviewed, evidence, domains və cross-reference.
## Data əldə etmə və API
REST search/stream/entry API; FASTA/TSV/JSON.
## İstifadə halı
P01308 insulin sequence analizi.
## Layihə fikri
Evidence-aware protein function classifier.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [UniProt](https://www.uniprot.org/help/api). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
