# STRING

## Məqsəd
Protein functional association şəbəkəsi.
## Saxlanan məlumat
Experimental, curated, coexpression və digər evidence channels.
## Data əldə etmə və API
REST API və downloads; species taxon ID-ni verin.
## İstifadə halı
Candidate genlərin network context-i.
## Layihə fikri
Evidence channel ablation ilə hub sırasının sabitliyi.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [STRING](https://string-db.org/help/api/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
