# SRA

## Məqsəd
Xam sequencing read arxivi.
## Saxlanan məlumat
Run, experiment, sample və study metadata; sequencing reads.
## Data əldə etmə və API
SRA Toolkit prefetch/fasterq-dump, Entrez; ENA-dan FASTQ alternativi.
## İstifadə halı
RNA-seq və WGS pipeline-nı başdan qurmaq.
## Layihə fikri
QC filtrinin mapping nəticəsinə təsiri.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [SRA](https://www.ncbi.nlm.nih.gov/sra/docs/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
