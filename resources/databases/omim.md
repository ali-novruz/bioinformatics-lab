# OMIM

## Məqsəd
Mendel irsiyyəti və insan gene–phenotype bilik bazası.
## Saxlanan məlumat
Ekspert mətnləri, gene/phenotype və allelic variant əlaqələri.
## Data əldə etmə və API
Web və qeydiyyat/lisenziya şərtləri ilə API; bulk scraping etməyin.
## İstifadə halı
Rare disease gene araşdırması.
## Layihə fikri
HPO ilə Mendelian candidate ranking; giriş icazəsi tələb oluna bilər.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [OMIM](https://www.omim.org/help/faq). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
