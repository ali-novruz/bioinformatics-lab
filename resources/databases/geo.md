# GEO

## Məqsəd
Functional genomics eksperiment arxivi.
## Saxlanan məlumat
GSE series, GSM samples, GPL platforms; expression matrix və supplementary fayllar.
## Data əldə etmə və API
GEO web/FTP; metadata üçün Entrez/GEOquery yolları.
## İstifadə halı
Pasilla treatment effect-i.
## Layihə fikri
Eyni xəstəlikdə platformalararası expression təkrarı.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [GEO](https://www.ncbi.nlm.nih.gov/geo/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
