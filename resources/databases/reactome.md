# Reactome

## Məqsəd
Kurasiya edilmiş bioloji reaksiyalar və pathways.
## Saxlanan məlumat
Reaction hierarchy, iştirakçı molekullar və species mapping.
## Data əldə etmə və API
Content Service və Analysis Service API, downloads.
## İstifadə halı
Differential genes üçün pathway enrichment.
## Layihə fikri
Gene background seçimində enrichment sabitliyi.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [Reactome](https://reactome.org/ContentService/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
