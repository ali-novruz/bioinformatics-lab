# ENA

## Məqsəd
Avropa nukleotid arxivi və INSDC tərəfdaşı.
## Saxlanan məlumat
Reads, assembly, sequence və sample metadata.
## Data əldə etmə və API
Browser API, Portal API və FTP/HTTPS.
## İstifadə halı
Run accession-dan paired FASTQ URL-ləri.
## Layihə fikri
Mikrob run-larının sequencing platformaya görə QC müqayisəsi.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [ENA](https://www.ebi.ac.uk/ena/browser/api/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
