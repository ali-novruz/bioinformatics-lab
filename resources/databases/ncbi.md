# NCBI

## Məqsəd
Molekulyar biologiya və elmi informasiya xidmətləri üçün portal.
## Saxlanan məlumat
Nucleotide, Gene, protein, taxonomy və ədəbiyyat əlaqələri.
## Data əldə etmə və API
Web, E-utilities, NCBI Datasets CLI/API. Sorğu sürəti qaydaları və email/API key tövsiyələrini rəsmi sənəddən yoxlayın.
## İstifadə halı
Gene ID-dən sequence və məqaləyə keçid.
## Layihə fikri
Bir gen üçün versiyalı evidence dossier.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [NCBI](https://www.ncbi.nlm.nih.gov/home/develop/api/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
