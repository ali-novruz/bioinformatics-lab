# Ensembl

## Məqsəd
Genome annotation və comparative genomics.
## Saxlanan məlumat
Genes, transcripts, variation, orthology və regulation.
## Data əldə etmə və API
REST API, BioMart və FTP; release və genome assembly pin edin.
## İstifadə halı
Variantı transkript nəticəsi ilə annotate etmək.
## Layihə fikri
Ortholog genlərdə conservation və expression müqayisəsi.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [Ensembl](https://rest.ensembl.org/). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
