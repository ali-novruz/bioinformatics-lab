# GTEx

## Məqsəd
İnsan toxumalarında expression və genetic regulation.
## Saxlanan məlumat
Tissue expression, eQTL/sQTL və metadata.
## Data əldə etmə və API
Portal downloads/API imkanları; individual-level controlled məlumat üçün dbGaP icazəsi.
## İstifadə halı
Tissue specificity və eQTL konteksti.
## Layihə fikri
Bir genin toxumalararası expression dəyişməsi.
## Keyfiyyət nəzarəti
Accession/ID, release, query, retrieval date, species, referens build və istifadə şərtlərini dataset kartına yazın. Sample və donor sayını fərqləndirin. Qaytarılan metadata-nı kor-koranə biological ground truth qəbul etməyin.

Rəsmi başlanğıc: [GTEx](https://gtexportal.org/home/datasets). Link əlçatanlığı və API imkanları xidmətlə dəyişə bilər; dəqiq endpoint və limitlər üçün bu sənədi oxuyun.
