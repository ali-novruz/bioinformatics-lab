# Kitablar və uzun kurs mətnləri

| Resurs | Nə üçün | Oxu tapşırığı |
|---|---|---|
| [Molecular Biology of the Cell — NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/NBK21054/) | DNA, RNA, protein və hüceyrə biologiyası; açıq köhnə nəşr | Central dogma və gene regulation xəritəsi |
| [Bioinformatics Algorithms — müəllif saytı](https://www.bioinformaticsalgorithms.org/) | Sequence algorithms və hesablama düşüncəsi | DP recurrence-ni koddan əvvəl əl ilə həll edin |
| [Modern Statistics for Modern Biology](https://web.stanford.edu/class/bios221/book/) | R, reproducibility, count və multivariate data | Bir statistik nümunəni Python-a köçürüb fərziyyələri müqayisə edin |
| [An Introduction to Statistical Learning](https://www.statlearning.com/) | Classification, regularization, resampling | Nested CV sxemi və leakage nümunəsi |

Linklər materialların öz səhifələrinə aparır; kitabları icazəsiz repoya köçürməyin. Köhnə biologiya mətnindəki anlayışları cari database/tool sənədlərindən ayırın.
