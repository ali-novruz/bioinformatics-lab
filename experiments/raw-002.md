# Raw sequencing icrası — 2026-09-16

**Status:** tamamlanmış kiçik Linux icrası.

## Sual

Windows-da mövcud olmayan alətləri GitHub Actions Linux runner-də işlədərək
FASTQ-dan ölçülə bilən nəticəyə qədər yol təkrarlana bilirmi?

## Dataset və dizayn

- Sintetik positive control: 6 kb unique reference, 422 paired fragment, bir məlum SNV.
- Real RNA: GSE110004, üç uninduced və üç IAA 30 min sample, hərəsi 50,000 chrI pair.
- Xarici DNA: nf-core/sarek tiny normal sample, beş lane; biological truth təsdiqlənməyib.

## Xətalar və düzəlişlər

1. İlk Linux quraşdırmasında `star` adlı Ubuntu paketi tapılmadı. STAR Bioconda-dan quraşdırıldı.
2. Əl ilə yazılmış FASTQ-da read və quality uzunluqları fərqli idi.
   Seed-li generator və müstəqil Biopython parser testi ilə əvəz edildi.
3. Təkrarlanan reference meaningful mapping nəzarəti vermirdi.
   Unikal reference, məlum PASS variant və minimum assigned-fragment yoxlamaları əlavə edildi.
4. CI komponentləri cari release commit-lərinə sabitləşdirildi;
   Conda aktivləşməsi Linux login shell-də açıq quruldu.

## Müşahidə

Positive control keçdi. Real RNA-nın 300,000 read pair-i işləndi; 84 gen modelə
daxil oldu. Bir gen FDR<0.05 verdi, |log2FC|>1 həddini keçən significant gen olmadı.
Xarici DNA-da 32 variant (27 PASS) alındı. QC-də qalan WARN/FAIL-lər saxlanıldı.
[Tam nəticə və fayllar](../results/raw-examples/README.md).

## Interpretasiya və növbəti sınaq

Runtime maneəsi aradan qaldırıldı. Kiçik xam dataset icrası bu workflow-ların
texniki işlədiyini göstərir. Biological accuracy üçün ayrıca truth regions,
tam reference, uyğun consequence annotation və müstəqil cohort lazımdır.
Növbəti məqsəd daha çox gen/discovery almaq üçün hədləri dəyişmək deyil:
tam dataset və əvvəlcədən müəyyən edilmiş dizaynla nəticəni yoxlamaqdır.
